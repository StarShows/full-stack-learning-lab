Application & identity

Blank secret fields preserve existing values. Secrets are saved privately on this machine and are never returned to this page. Saving does not restart the app.

Register Google and Apple sign-in

Google Cloud Console: create a Web OAuth client and register APP_URL/auth/google/callback. Apple Developer: configure a Service ID and register APP_URL/auth/apple/callback. Apple requires a public HTTPS domain and a private signing key. Registration must be completed in the provider account.

Server connection

Linux, Docker Engine, Compose v2, and a TLS reverse proxy must already be installed. Use a dedicated deployment user with Docker permission. Verify the SSH host fingerprint out of band and add it to your known_hosts file. Load your key into ssh-agent; no private key is uploaded here.

Verification

Tests and builds run on this source checkout. Health and model checks run on your selected server. Model checks may consume tokens when a remote provider is configured.

Deploy & operate

Deployment runs tests, transfers an explicit source archive and private configuration over SSH, builds containers, then checks application health. Database volumes persist. Configure TLS before deploying; public traffic should reach only your reverse proxy.

Deployment is not an atomic database rollback. Retained releases allow manual recovery after reviewing schema compatibility. Back up your database before upgrades.
